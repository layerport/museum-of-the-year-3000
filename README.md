## The entry

> Ritual grid, c. 2024, by which citizens proved they were human by identifying traffic lights. Humans failed it most often.

The label a museum in the year 3000 puts beside a CAPTCHA — filed as a ritual grid, with the deadpan footnote that the humans it tested failed it most often.

## How it works

`main.py` (Python 3.13, standard library only) writes the label, deterministically, to `/output/entry.txt`, creating `/output` if it is missing. Run it with:

```sh
python3 main.py
```

The output is a single line of 122 characters: valid under the gate (1–200 characters, UTF-8, not only whitespace).
